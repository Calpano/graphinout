== Conceptual Mapping
=== OCIF -> CJ

|===
| OCIF | CJ

| Document | Document
| Node | Node or Edge
| Resource | Document.data
| Representation | Document.data
| Schema | Document.data
|===

=== CJ -> OCIF
|===
| CJ | OCIF

| Document | Document
| Graph | Node [synthetic]
| Node | Node
| Edge | Node (sometimes with Extension)
| Port | Node > Port Extension
| Label | Node.resource & Representation
|===

== Mapping OCIF Resources and CJ Labels

- OCIF resources with mimeType=text/plain maps to CJ labels without language


[cols="l,d"]
|===
| OCIF Path                                | Type

|/nodes/*/resource                         | string?
|/resources/*/id                           | string!
|/resources/*/representations              | Array!
|/resources/*/representations/*            | Object
|/resources/*/representations/*/mediaType  | string?
|/resources/*/representations/*/content    | string?

h| CJ Path                                h| Type

|/graphs/*/nodes/*/label                   | Object?
|/graphs/*/nodes/*/label/language          | string?
|/graphs/*/nodes/*/label/value             | string!
|/graphs/*/nodes/*/data                    | Object

|===

.OCIF Constraint
`/nodes/$OCIF_NODE/resource` == `/resources/$OCIF_RESOURCE/id`

`/resources/$OCIF_RESOURCE/representations/$OCIF_REP/mediaType`
`/resources/$OCIF_RESOURCE/representations/$OCIF_REP/content`


`/graphs/$CJ_GRAPH/nodes/$CJ_NODE/label/language`
`/graphs/$CJ_GRAPH/nodes/$CJ_NODE/label/value`


.Cases
1 OCIF Representation with mimeType=text/plain <==> 1 CJ LabelEntry

.Insights
- Any OCIF resource with multiple representations needs to be fully intact to preserve representation order
- A CJ label entry with a language can be mapped to an OCIF representation with a CJ extension.
- An OCIF resource with *only* text/plain representations can map to a CJ label with multiple entries

.OCIF to CJ
|===
| OCIF resource | CJ label | OCIF resources in CJ doc data

| 1 text/plain  | 1 label entry | --
| n text/plain  | n label entry | --

| mixed mimeTypes | 1 label entry | all
|===

.CJ to OCIF
|===
| CJ label | OCIF resources in CJ doc data | OCIF resource

| content | -- | text/plain
| language | -- | data[type=@cj/label]/language
|===
