## Reporting a Vulnerability

To report a vulnerability, please (file an issue)[https://github.com/Calpano/graphinout/issues].
As an open source project, we currently work on a best-effort basis on this.
If you need reliable service, [ITMV](https://maxvoelkel.de) can provide it commercially.
