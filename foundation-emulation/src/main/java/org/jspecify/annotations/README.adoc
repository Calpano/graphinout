= jspecify

We cannot simply depend on `jspecify`, because the sources are not Java 8 compatible. They use the new (Java 9) `MODULE` annotation location.

So we bundle these annotations themselves.
However, we also cannot use `@NullMarked`, as that leads to j2cl dying with
