= Graph Exchange File Formats
:toc:

This document provides an overview of various graph exchange file formats, based on the paper "Unravelling Graph-Exchange File Formats" by Roughan and Tuke (2015).

== Text-based Formats

=== TGF (Trivial Graph Format)
* Type: Text-based
* Specification: https://en.wikipedia.org/wiki/Trivial_Graph_Format[Wikipedia]

=== DOT Language
* Type: Text-based
* Specification: https://graphviz.org/doc/info/lang.html[spec]

=== Pajek
* Type: Text-based
* Specification: http://vlado.fmf.uni-lj.si/pub/networks/pajek/doc/pajekman.pdf[spec]

=== Nested Network Format
* Type: Text-based
* Specification: No formal specification found. Primarily used by Cytoscape.

=== BioGRID Tab 3.0 Format
* Type: Text-based
* Specification: https://wiki.thebiogrid.org/doku.php/biogrid_tab_version_3.0[spec]

=== PSI-MI Tab Version 2.5 Format
* Type: Text-based
* Specification: https://bmcbiol.biomedcentral.com/articles/10.1186/1741-7007-5-44[spec]

=== Matrix Market
* Type: Text-based
* Specification: https://math.nist.gov/MatrixMarket/formats.html#MMformat[spec]

=== Adjacency Matrix/List
* Type: Text-based
* Specification: No formal specification. It's a general representation method.

=== Chaco
* Type: Text-based
* Specification: No formal specification found.

=== Edge List
* Type: Text-based
* Specification: No formal specification. It's a general representation method.

=== GDF (Graph Data Format)
* Type: Text-based
* Specification: No formal specification found.

=== DL
* Type: Text-based
* Specification: No formal specification found.

=== Graph6
* Type: Text-based
* Specification: No formal specification found.

=== GML (Graph Modelling Language)
* Type: Text-based
* Specification: https://en.wikipedia.org/wiki/Graph_Modelling_Language[Wikipedia]; http://www.graphviewer.nl/misc/gmllanguage/gml-technical-report.pdf[spec 1997]

== XML-based Formats

=== GraphML
* Type: XML-based
* Specification: http://graphml.graphdrawing.org/specification.html[GraphML Specification]

=== GEXF (Graph Exchange XML Format)
* Type: XML-based
* Specification: http://gexf.net/schema.html[specification], http://gexf.net/basic.html[examples]

=== GXL (Graph eXchange Language)
* Type: XML-based
* Specification: https://en.wikipedia.org/wiki/GXL[Wikipedia]

=== XGMML
* Type: XML-based
* Specification: https://en.wikipedia.org/wiki/XGMML[spec]

=== SBML (Systems Biology Markup Language)
* Type: XML-based
* Specification: http://sbml.org/documents/[spec]

== Triple-based Formats

=== Turtle
* Type: Text-based
* Specification: https://www.w3.org/TR/turtle/[spec]

=== RDF/XML
* Type: XML-based
* Specification: https://www.w3.org/TR/rdf-syntax-grammar/[spec]

=== N3
* Type: Text-based
* Specification: https://www.w3.org/TeamSubmission/n3/[spec]

=== N-Triples
* Type: Text-based
* Specification: https://www.w3.org/TR/n-triples/[spec]

=== Web Ontology Language (OWL)
* Type: XML-based
* Specification: https://www.w3.org/TR/owl2-overview/[spec]

=== BioPAX (Biological PAthways eXchange) Format
* Type: OWL-based
* Specification: http://www.biopax.org/[spec]
