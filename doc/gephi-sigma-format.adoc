= Gephi JSON Exporter Data Format
:toc: left
:icons: font
:source-highlighter: highlight.js

This document describes the JSON output format generated by the `uk.ac.ox.oii.jsonexporter.JSONExporter` class for Gephi.
It is modeled to be importable by `Sigma.js`.
It is based on the _Graphology_ format.

.Refs
- https://gephi.org/desktop/plugins/jsonexporter-plugin/[]
- https://graphology.github.io/serialization.html#format[]
** https://zenodo.org/records/14835805[]

== Overview
The exporter generates a single JSON object containing the graph data. The root object contains two primary arrays representing the vertices and connections of the network.

[source,json5]
----
{
    "nodes": [ /*...*/ ],
    "edges": [ /*...*/ ]
}
----

== Data Structure

=== Node Objects

Each element in the nodes array represents a graph vertex. The data is derived from the Gephi GraphModel.

.Node Fields
[cols="1,1,3", options="header"]
|===
| Key | Type | Description

| id
| String
| The unique string identifier of the node.

| label
| String
| The display label of the node.

| x
| Float
| The horizontal position on the layout space.

| y
| Float
| The vertical position on the layout space.

| size
| Float
| The radius/size of the node.

| color
| String
| The node color formatted as a CSS RGB string (e.g., rgb(255,0,0)).

| [attributes]
| String
| Any other column found in the Gephi Data Laboratory (e.g., "Modularity Class", "Betweenness Centrality").
|===

[NOTE]

Excluded Fields: The columns "id" and "label" are excluded from the generic attributes list as they are mapped to specific properties.

Null Values: Attributes with null values are omitted from the output.

=== Edge Objects

Each element in the edges array represents a connection between two nodes.

.Edge Fields
[cols="1,1,3", options="header"]
|===
| Key | Type | Description

| id
| String
| The unique identifier of the edge.

| source
| String
| The id of the starting node.

| target
| String
| The id of the ending node.

| size
| Float
| Represents the edge weight.

| label
| String
| The text label of the edge.

| color
| String
| The edge color formatted as a CSS RGB string.
|===

==== Edge Color Logic
The exporter determines edge color using the following priority:

Explicit Color: If the edge has a specific color (alpha != 0), that color is used.

Mixed Color: If no color is set, the exporter calculates a mixed color based on the Source Node and Target Node colors.

==== Edge Attributes
Similar to nodes, custom columns in the Edge Data Table are exported as key-value pairs.

The column "weight" is excluded from the attributes list as it is mapped to the size property.
