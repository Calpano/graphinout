== TGF (Trivial Graph Format)
* Type: Text-based
* Specification: https://en.wikipedia.org/wiki/Trivial_Graph_Format[Wikipedia]

.Example Syntax
----
1 First node
2 Second node
#
1 2 Edge between the two
----

|===
| Feature | Present? | Notes
| Multiple Graphs per Document | -- |

| Undirected Edges | + | Default interpretation
| Directed Edges | (+) | Tool-dependent interpretation
| Hyperedges | -- |
| Mixed-directionality Edges | -- |
| Edges on Edges | -- |
| Nested Graphs in Nodes | -- |
| Nested Graphs in Edges | -- |
| Nested Graphs in Graphs | -- |
| Node Labels | + | After node ID
| Edge Labels | + | After edge endpoints
| Attributes on Nodes | -- |
| Attributes on Edges | -- |
| Attributes on Graphs | -- |
| Typed Edges | -- |
|===

== DOT Language
* Type: Text-based
* Specification: https://graphviz.org/doc/info/lang.html[spec]

.Example Synax
[source,dot]
----
digraph sample2 {
 A -> B [ label = "Edge A to B" ];
 B -> C [ label = "Edge B to C" ];
 A [label="Node A"];
}
----

[cols='3d,^1d,2d']
|===
| Feature | Present? | Notes
| Multiple Graphs per Document | -- | One graph per file
| Nodes | + |
| Undirected Edges | + | `graph` with `--` operator
| Directed Edges | + | `digraph` with `\->` operator
| Hyperedges | -- |
| Mixed-directionality Edges | -- | Graph is either directed or undirected
| Edges on Edges | -- |
| Nested Graphs in Nodes | + | Via subgraphs/clusters
| Nested Graphs in Edges | -- |
| Nested Graphs in Graphs | + | Via subgraphs/clusters
| Node Labels | + | Via `label` attribute
| Edge Labels | + | Via `label` attribute
| Attributes on Nodes | + | Extensive attribute system
| Attributes on Edges | + | Extensive attribute system
| Attributes on Graphs | + | Extensive attribute system
| Typed Edges | -- |
|===
