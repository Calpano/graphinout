= Graphinout CLI

A command-line interface for Graphinout: read a graph file in one of the supported
input formats and convert it to one of the supported output formats.

All readers and writers are discovered at runtime via the `GioService` `ServiceLoader`,
so the available formats reflect whichever reader modules are on the classpath (the `cli`
module depends on `engine`, which pulls in all readers).

== Build

[source,shell]
----
mvn -pl cli -am clean package
----

This produces a self-contained, runnable jar:

----
cli/target/cli-<version>-cli.jar
----

== Run

[source,shell]
----
# List all supported input and output formats
java -jar cli/target/cli-<version>-cli.jar formats

# Convert, writing to a file
java -jar cli/target/cli-<version>-cli.jar convert graph.gml --to graphml --output graph.graphml.xml

# Convert, writing Connected JSON to stdout (default output format is graphml)
java -jar cli/target/cli-<version>-cli.jar convert graph.tgf --to connected-json
----

== `gio` launcher

A `gio` wrapper script lives at `cli/bin/gio`. It locates the shaded jar relative to itself
(building it on first use if missing) and forwards all arguments, so it works from any directory.

Put it on your `PATH`:

[source,shell]
----
ln -s "$(pwd)/cli/bin/gio" /usr/local/bin/gio
# or
export PATH="$PATH:$(pwd)/cli/bin"

gio formats
gio convert graph.gml --to connected-json
----

Pass extra JVM options via `GIO_JAVA_OPTS`, e.g. `GIO_JAVA_OPTS=-Xmx2g gio convert big.graphml.xml`.

== Commands

[cols="1,3"]
|===
| `formats` | List supported input (readers) and output (writers) formats
| `convert <input> [options]` | Convert a graph file to another format
| `version` | Print the version
| `help` | Show usage
|===

=== `convert` options

[cols="1,3"]
|===
| `-t`, `--to <id>` | Output format id (default: `graphml`)
| `-o`, `--output <file>` | Write to a file instead of stdout
| `-f`, `--from <id>` | Force the input format id (default: auto-detect by extension + content probing)
| `-a`, `--anonymize` | Redact labels, types and content before writing (see below)
|===

Parse warnings and progress messages go to `stderr`; the converted graph goes to `stdout`
(or the `--output` file), so piping stdout yields clean output.

=== `--anonymize`

Redacts copyrightable / private material while preserving the graph structure, so a sanitized copy
can be published. Letters become `X`/`x`, digits become `0`, and spacing and punctuation are kept;
node/edge/graph/port ids are remapped to `node1`, `edge1`, … (consistently, so links stay intact);
and JSON keys in `data`/`meta` are remapped to `key1`, `key2`, …

[source,shell]
----
gio convert patient-graph.gml --to connected-json --anonymize
# "Node 1" -> "Xxxx 0";  "Edge from 1 to 2" -> "Xxxx xxxx 0 xx 0"
----

Full details: link:../base/anonymization.adoc[base/anonymization.adoc].
