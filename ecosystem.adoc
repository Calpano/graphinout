== Graph Formats
See https://github.com/Calpano/graph-format-registry[].

* Text based: Diverse text syntaxes to encode graphs.

* XML based: Expressed as XML.
* link:src/main/doc/graphml.adoc[GraphML] (<- our notes about the format)

* JSON based: In JSON format.
Common formats:

* Connected JSON https://j-s-o-n.org (NEW, not in the paper)

* Triple based: Triples (semantic web) can be encoded themselves as XML or text-based syntaxes.
They are used for knowledge graphs, vocabularies, linked open data and ontologies.
