= Changelog
:toc:

All notable changes to GraphInOut, newest first. Format based on
https://keepachangelog.com[Keep a Changelog]. Releases are tagged
`graphinout-<version>`; library modules publish to Maven Central and the `gio` CLI
ships via GitHub Releases. Curated from git history — routine merges, dependency
bumps and "minor/doc/WIP" commits are omitted.

== Unreleased

== 0.2.1 — 2026-07-06

Added::
* Identity-based, ranked-confidence format detection with a `gio detect` command;
  ranking now weighs extension, content kind, vocabulary/signatures and graph
  plausibility rather than recovered graph size.
* `gio meta` — type-schema inference (node/edge types as counted nodes, `uses`
  links, `has subtype` generalisation) — plus a `convert --meta` flag.
* `reader-jgef` — JSON Graph Entry Format (GEF) reader.
* `self-loops` and `parallel-edges` to the `CjFeature` vocabulary.
* `LICENSES/` folder reproducing every (transitive) dependency's own license text,
  linked from `THIRD_PARTY.adoc`; `archive-concept.adoc` design note.
* A write-time `ContentError` channel for output writers (`GioWriter.setContentErrorHandler`):
  the format writers (GML, DOT, D2, Mermaid, TGF) now report graph data the target format cannot
  represent (hyper-edges, nodes without ids); the CLI `convert` surfaces it on stderr.

Changed::
* `AnonymizingCjStream` and the meta-graph collector are now streaming (only id/key
  maps or a type projection are buffered, not the whole document).
* GraphML/GEXF readers stream-decode HTML named entities, and GraphML parses
  non-standard `attr.type`/`edgedefault` leniently (warn instead of fail).
* Harmonized transitive dependency versions to a single resolved version each.
* Readers report parse problems through the `ContentError` handler instead of logging them
  directly, and cap the reports once an input clearly isn't their format (GML, GraphML, GEXF,
  OCIF, CJ, RDF) — removing incidental log noise during format detection.
* OCIF assumes **v0.7** (was v0.6) when a document declares no schema.
* Published POMs are flattened for Maven Central (self-contained: resolved dependency versions
  plus project metadata) via `flatten-maven-plugin`.

Removed::
* The whole-document anonymizer (the streaming one replaces it, verified equivalent
  across the test corpus).

Fixed::
* `CjWriter2CjStream`: graph-level `data` field dropped when it appears after `nodes` in the JSON;
  nested subgraph structures lost in stream output.
* `CjValidator`: false-positive "no nodes or edges" warning for graphs that contain only nested subgraphs.
* The Neo4j writer reports a `ContentError` when a document has no nodes or edges to export,
  instead of silently producing empty output.

== 0.2.0 — 2026-06-16

Added::
* `reader-plantuml` (PlantUML class diagrams) and `reader-structurizr-dsl`.
* Adjacency-list and edge-list readers + writers; feature-based round-trip tests.
* GEXF 1.3 round-trip support; OCIF upgraded to the v0.7.1-draft spec with inline
  resources; `CjGraphStructureCanvasExtension` to preserve the CJ tree on OCIF
  round-trips.
* `SchemaCache` for GraphML validation; Connected JSON upgraded to the v8.0.0 schema.

Changed::
* DOT, GML, Mermaid and D2 readers gained nested graphs, mixed directed/undirected
  edges, compound nodes and subgraph syntax.
* Normalized TGF edge handling (undirected semantics) and edge normalization.

== 0.1.14 — 2026-06-15

Added::
* GEXF reader (closes #141); experimental GTFS topology support; `reader-ddot`,
  `reader-mermaid`, `reader-d2`; preliminary OCIF 0.7; `about.ddot` for every reader.

Changed::
* GraphML schemas resolve offline (`GraphmlValidator`); logging moved to `slf4j-api`
  with `logback-classic` at test scope; Jackson aligned with Spring Boot 4.0.6.
* Javadoc added across `foundation-pure` and `base` (#30).

Fixed::
* DOT reader dropping node attributes (#133); GraphML edges hoisted to a common
  ancestor graph (#137); `findNodeById` on compound/nested graphs; GML input
  validation reports ContentErrors (#140); `reader-ddot` preserves untyped links.

== 0.1.13 — 2026-02-11

Added::
* `RdfReader`/`RdfWriter` for many RDF syntaxes, with RDF canonicalization and
  round-trip testing; experimental `pg-format` and Neo4j LPG readers.
* `node.types`, `ParameterizedInputSource`, and a `CjValidator`.

Changed::
* Migrated to the Connected JSON 7.0.0 spec; replaced the `baseUri` concept with a
  JSON-LD `@context` namespace map; `label`-array migrated to `label`-entries.

Fixed::
* GraphML URI handling and hyperedge validation (allow `GRAPH` in a hyperedge).
